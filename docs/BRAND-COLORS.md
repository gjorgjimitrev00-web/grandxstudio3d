# GrandXStudio brand colors

Primary brand color: **#FE7F2D** (RGB 254, 127, 45), selected by the owner on
20 October 2026. Use this same orange for future Instagram story artwork.

Website tokens live in `src/app/globals.css`:

| Token           | Color     | Use                                                                     |
| --------------- | --------- | ----------------------------------------------------------------------- |
| `--brand`       | `#FE7F2D` | Primary buttons, logo X, sale badges, chat launcher, decorative accents |
| `--brand-hover` | `#ED6E1E` | Hovered primary actions                                                 |
| `--brand-ink`   | `#A34209` | Orange text on light backgrounds, focus rings, selected form controls   |
| `--brand-soft`  | `#FFF0E5` | Pale orange panels and selected navigation                              |
| `--brand-line`  | `#F2C6A5` | Borders on pale orange panels                                           |
| `--ink`         | `#252922` | Body text and labels on orange buttons                                  |

Use dark text on the primary orange: its contrast ratio is 5.84:1, and the hover
color retains 4.83:1. Small orange text uses `--brand-ink`, with 6.17:1 contrast
against the page background and 5.64:1 against pale orange.

Product colors and photographs are independent of the interface palette. Keep
success, availability and error indicators semantically distinct.

The existing story exports remain as delivered. When the owner requests the next
story update, use the primary orange for the artwork's accents and new screenshots
of the updated website. Preserve the approved original layouts and logo preference.
